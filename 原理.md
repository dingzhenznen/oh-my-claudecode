它们是 OMC 在运行时动态创建的 sub-agent，通过 Agent 工具调用，传入不同的 prompt 角色描述。

  也就是说：

  autopilot skill 执行时
      └── 调用 Agent 工具，传入 "你是 Analyst，负责需求分析..."
      └── 调用 Agent 工具，传入 "你是 Architect，负责技术设计..."
      └── 调用 Agent 工具，传入 "你是 Executor，负责实现..."

  这些 agent 的 prompt 是内嵌在各个 skill 的 SKILL.md 文件里的，不是单独的文件。omc-reference 里列出的 agent
  目录只是文档说明，实际上没有对应的独立文件。

  所以你的 OMC 安装是完全正常的

  ┌────────────────────────────────────┬──────────────────────────────────────────────────────────────────────┐
  │              你的疑问              │                               实际情况                               │
  ├────────────────────────────────────┼──────────────────────────────────────────────────────────────────────┤
  │ ~/.claude/agents/ 为空             │ 正常，OMC 不依赖这个目录                                             │
  ├────────────────────────────────────┼──────────────────────────────────────────────────────────────────────┤
  │ ~/.claude/skills/ 没有 executor 等 │ 正常，这些 agent prompt 内嵌在 autopilot/ralph/ultrawork 等 skill 里 │
  ├────────────────────────────────────┼──────────────────────────────────────────────────────────────────────┤
  │ OMC 能不能用                       │ 完全可以用，所有 workflow skill 都在                                 │
  └────────────────────────────────────┴──────────────────────────────────────────────────────────────────────┘

  运行 /autopilot、/ralph、/ultrawork 等，它们内部会自动创建所需的 sub-agent
