OMC Task 工具 vs Agent 工具的关系                                                                    
                                                                                                       
  ┌─────────────────────────────────────┐                                                              
  │         OMC Task 工具               │                                                              
  │    (oh-my-claudecode 封装层)        │                                                              
  └─────────────┬───────────────────────┘                                                              
                │ 内部调用                                                                             
                ▼                                                                                      
  ┌─────────────────────────────────────┐                                                              
  │      Claude Code Agent 工具         │                                                              
  │      (原生底层能力)                  │                                                             
  └─────────────┬───────────────────────┘                                                              
                │ 创建                                                                                 
                ▼                                                                                      
  ┌─────────────────────────────────────┐                                                              
  │    子代理 (general-purpose 等)       │                                                             
  │    (实际执行任务的进程)               │                                                            
  └─────────────────────────────────────┘                                                              
                                                                                                       
  类比理解                                                                                             
                  
  ┌───────────────┬────────────────┬──────────────────────────────┐                                    
  │     层级      │      类比      │             作用             │
  ├───────────────┼────────────────┼──────────────────────────────┤                                    
  │ OMC Task 工具 │ 高级 API / SDK │ 提供专业化、预配置的代理类型 │
  ├───────────────┼────────────────┼──────────────────────────────┤
  │ Agent 工具    │ 底层系统调用   │ 创建和管理子代理进程         │                                    
  ├───────────────┼────────────────┼──────────────────────────────┤                                    
  │ 子代理        │ 工作进程       │ 实际执行任务                 │                                    
  └───────────────┴────────────────┴──────────────────────────────┘                                    
                  
  具体例子                                                                                             
                  
  OMC 定义了 oh-my-claudecode:architect，它内部可能是：                                                
                  
  // 伪代码示意                                                                                        
  function createArchitectAgent(prompt) {                                                              
    return Agent.create({                                                                              
      subagent_type: "general-purpose",  // 底层还是 general-purpose                                   
      model: "opus",                      // 但配置了更强的模型                                        
      system_prompt: "你是架构师专家...", // 加上专业角色设定                                          
      user_prompt: prompt                                                                              
    });                                                                                                
  }                                                                                                    
                                                                                                       
  总结                                                                                                 
  
  - Agent 工具：Claude Code 的原生能力，创建子代理进程                                                 
  - OMC Task 工具：在 Agent 基础上的封装和扩展，提供：
    - 预定义的专业角色（architect, security-reviewer 等）                                              
    - 预配置的模型选择（opus 用于复杂任务）                                                            
    - 标准化的调用接口                                                                                 
                                                                                                       
  所以 OMC 的 Task 工具是更高层的抽象，底层确实依赖 Claude Code 的 Agent 工具来实际创建子代理。
